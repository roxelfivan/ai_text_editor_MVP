# v0.5.1 — Phase 1 polish + Phase 2 daily friction

Patch release on top of [v0.5.0](https://github.com/roxelfivan/apeditor/releases/tag/v0.5.0). Completes the UX roadmap **Phase 1** (clarity and gated states) and **Phase 2** (selection-only send, secret redaction, outdated-comment cleanup, session-only API key). Export Markdown, import size caps, and best-effort Apply remain as shipped in v0.5.0.

## Added

- **Chat selection only.** A **selection only** checkbox (disabled until there is a highlight) omits the document outline and sends the highlight as working text. User bubbles show **▸ selection only**.
- **Selection delimiters.** Highlights in outbound prompts (OpenAI path and Google AI Mode) use `----- BEGIN EDITOR SELECTION -----` / `----- END EDITOR SELECTION -----`.
- **Outbound secret redaction.** `sk-…`, Bearer tokens, and `api_key=`-style assignments in the request payload are replaced with `[redacted]`. The document is not rewritten. Chat shows a quiet count when anything was redacted.
- **Dismiss outdated.** Comment tray button deletes every outdated comment on the current document. `⌘Z` undoes one at a time.
- **Re-attach.** Outdated comment popover can re-anchor to the current editor selection.
- **Forget API key when this tab closes.** Settings checkbox stores the key in `sessionStorage` and strips it from the persisted zustand blob.

## Changed

- **Predict (Google AI Mode).** Disabled Predict tooltip: *Predict is not available with Google AI Mode — type your prompt in the Chat panel instead.* `aria-disabled` mirrors the disabled state.
- **`@` picker.** Does not open with fewer than two sidebar documents. Textarea title: *Open a second document in the sidebar to use @-references.*
- **Import popover.** Quiet hint when the key or endpoint is missing: Markdown rewrite needs a key.
- **⌘Z.** First empty comment-ops undo in a tab shows a one-shot toast that ApEditor undo is comment-ops only. Native textarea undo is not prevented.
- **Help / workspace docs.** Editor font size documented in the **Format** menu (`docs/workspace.md`), matching shipped **Size +** / **Size −**.
- **Apply All skip copy.** Points at **Apply anyway** / **Force-apply** on leftover cards.

## Removed

- Unused mentions chip-layout `useLayoutEffect` no-op in `MentionInput`.

## Behaviour that did NOT change

- Export Markdown, import 50 MB / 500 page / 200 MB batch caps, best-effort Apply (v0.5.0).
- Comment **Send to AI** still includes a compact document outline.
- Import still refuses Markdown rewrite without an API key (the new hint is proactive; the post-pick error remains).
- Versioned LLM prompt contracts other than selection delimiters and selection-only outline omission.

## Verification
