# v0.3.4 — Import → Markdown, OCR works under CSP, security hardening, topbar icons

A feature + maintenance release on top of v0.3.3. Photos and PDFs you import are now turned into clean Markdown by your configured chat model before anything is inserted into the document — no more raw OCR text in your editor. The OCR pipeline also now initializes correctly under the page's Content-Security-Policy, the top bar gets distinctive icons for the three most-used actions, and a focused security pass hardens how Markdown is rendered and how API keys are sent.

* **Import photos & PDFs → Markdown.** After OCR or PDF text extraction succeeds, the extracted text is sent to your configured chat model and rewritten as reader-friendly Markdown. Only the rewritten Markdown is inserted into the editor — the raw OCR text is never pasted. The same chat client as the rest of the app is used, with only the API key you configured in **Settings**; no built-in, Cursor, or fallback key. An API key is required, and images still stay entirely in your browser.

* **OCR works under the page CSP.** Photo / PDF import was failing under the v0.3.3 Content-Security-Policy because PaddleOCR pulls OpenCV.js (whose embind layer builds invokers with the `Function` constructor) and an ONNX Runtime bundle that fetches a `data:`-sourced WASM. OCR now initializes under the existing `script-src` policy: ONNX Runtime is aliased to the WASM-only extern build (so the WebGPU / JSEP embind path isn't loaded), and `unsafe-eval` plus `data:` are allowed specifically for the OCR path.

* **Topbar action icons.** The **History**, **Prompts**, and **Settings** buttons in the top bar are now distinct icons instead of text labels. History uses a clock, Prompts a bookmark, and Settings a gear with a missing-key badge. History and Prompts share the square outline treatment used by **Import** / **Save**; Settings keeps its filled fire treatment.

* **Import popover stays in the viewport on mobile.** The OCR language picker used to be absolutely right-aligned to the **Import** button; on a wrapped vertical mobile toolbar that put the panel off-screen. It now uses fixed coordinates clamped to the viewport on both edges, so it never overflows on a phone.

* **Security hygiene pass.** Markdown rendered from the chat model is now passed through `rehype-sanitize` after `rehype-raw` (keeping `<u>` for the toolbar's underline button). API requests refuse to send the Bearer token to non-HTTPS endpoints (`http://localhost` is still allowed for local dev). A baseline CSP meta tag has been added to `index.html`, and a new `SECURITY.md` documents the findings and residual risks. No secrets were found in the v0.3.3 tree.

* **Docs.** The seeded Welcome document was rewritten as a 7-step quick start, so first-time users see a guided path instead of a long reference page.
