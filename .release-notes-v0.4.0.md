# v0.4.0 — Comment + Send to AI, Google AI Mode, Predict label

Major feature release on top of v0.3.4.

* **Comment.** Select text in **Write** → click **Comment** → write your note. A highlight and numbered margin badge mark the passage. Open a badge to **Edit** or **Delete** (including after send). Click **Send to AI** under the editor to batch the article and every comment into one chat turn. Comments that cannot be re-anchored after edits show as **Outdated**. `⌘/Ctrl + Z` undoes the last comment change.

* **Google AI Mode (no key).** New Settings provider that opens Google AI Mode in a new tab with your prompt pre-filled. Paste the answer back into the chat panel. Proposed-edit cards (**Apply** / **Reject** / **Apply N changes**) still work. **Predict** stays unavailable for this provider.

* **Predict** label is title case (`Predict`), not all-caps.

* **Welcome** quick start rewritten so every control name matches the on-screen UI (**Write** / **Preview** / **Split**, **include selection**, **Revision history**, **Prompt library**, **Import text from photos or PDFs**, and so on).

* Mirror scroll sync rebinds when switching view modes so text keeps scrolling correctly in **Write** / **Split** after leaving **Preview**.
